# Подключение Gmail к ONROAD

## Текущее состояние

Отправка через SMTP реализована, но отдельный ящик и пароль приложения ещё не введены. Новые аккаунты не создаются, пока отправитель не настроен. Старые аккаунты могут продолжать входить. Наличие настройки само по себе не подтверждает доставку письма: после подключения нужна регистрация на собственную почту с получением и вводом кода.

## Локальное подключение

1. Создайте отдельный Gmail для ONROAD либо используйте уже созданный отдельный ящик.
2. Включите двухэтапную аутентификацию. В Google откройте [пароли приложений](https://myaccount.google.com/apppasswords) и создайте пароль для ONROAD. Этот шаг выполняет владелец аккаунта самостоятельно. Не присылайте пароль в чат.
3. В Терминале выполните:

```sh
cd /Users/alisher/Desktop/brd/BrandMyCar_axsh06
npm run mail:setup
```

4. Введите адрес отправителя и пароль приложения в появившиеся запросы. Пароль не отображается. Помощник сначала проверит вход в SMTP; при отказе настройки не сохраняются. Письмо на этом шаге не отправляется.
5. После успеха перезапустите сервер разработки (`npm run dev`), обновите форму регистрации, зарегистрируйтесь на свою почту и подтвердите код из письма.

Файл `.env.local` исключён из Git. Помощник сохраняет только настройки SMTP, сохраняя остальные локальные переменные. Обычный пароль Gmail не подходит. Google может не предлагать пароли приложений для некоторых типов аккаунтов или политик безопасности; см. [официальную справку](https://support.google.com/accounts/answer/185833?hl=ru).

## Vercel

После локального подключения задайте в настройках того же проекта Vercel переменные окружения **Production**:

| Имя | Значение |
| --- | --- |
| `EMAIL_FROM` | `ONROAD <адрес-ящика@gmail.com>` |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | Адрес отдельного ящика |
| `SMTP_PASSWORD` | Пароль приложения, вводится самостоятельно |

Если задан `RESEND_API_KEY`, приложение выбирает Resend. Для Gmail уберите эту переменную из соответствующего окружения. Не храните значения секретов в репозитории или скриншотах.

После сохранения окружения опубликуйте текущий код с миграциями через настроенный build `npm run deploy:build`. Затем проверьте уже публичную форму своим адресом: получение кода, подтверждение, вход и повторная отправка. Доставка в публичном окружении пока не подтверждена.

## Если письма не приходят

- Проверьте папку «Спам» и правильность адреса получателя.
- Убедитесь, что параметры заданы в нужном окружении Vercel и выполнено новое развёртывание.
- Если Google отклоняет SMTP-вход, заново выпустите пароль приложения и обновите настройку. Не отключайте проверку TLS.
- При сообщении о частых запросах дождитесь окончания ограничения. Коды действуют десять минут.

Gmail выбран для прототипа. Для массовой регистрации потребуется отдельно оценить объём отправки и выбрать подходящий транзакционный почтовый сервис.
